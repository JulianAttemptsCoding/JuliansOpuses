## Problem

Inside a burning building, GPS is unreliable or gone, smoke removes visual contact, and a crew can lose track of where its own members are. The project asks how to determine a firefighter's position in exactly those conditions.

## Starting with practitioners

The engineering started with a conversation. A battalion chief at the [Fremont Fire Department](https://www.fremont.gov/government/departments/fire) described what crews actually deal with: heavy smoke, no way to see team members, indoor positioning that cannot be trusted, very little time to deploy anything, and hard limits on what hardware a firefighter can carry.

Those constraints set the design. A crew cannot count on infrastructure installed in advance, so the reference points have to arrive with them, and setting them up cannot cost minutes.

## System concept

A small tag carried by the firefighter exchanges ultra-wideband (UWB) radio signals with several reference points whose positions are known. Each exchange gives a distance. Enough distances pin down a position: multilateration.

## What makes it hard

With exact ranges, the equations are a textbook exercise. The project is about everything that breaks them:

- **Noise.** Every range carries measurement error, and the position error it produces depends on where the reference points are.
- **Blocked paths.** A signal that passes through a wall or a stair core arrives late, so the range reads long. That is a bias, not noise, and averaging does not remove it.
- **Geometry.** Reference points placed where it is convenient, such as along one side of a building, amplify error in the direction they cannot see.
- **Height.** Knowing which floor someone is on makes this a 3D problem. Reference points that all sit near ground level barely constrain height; one placed well above them does.

## Estimation

The estimator is built for those failure cases rather than the ideal one: robust estimation that tolerates inconsistent ranges, and machine-learning-assisted correction of range error, particularly for measurements taken without a clear line of sight. Reference-point placement is treated as part of the system, because geometry sets how much any range error is amplified.
